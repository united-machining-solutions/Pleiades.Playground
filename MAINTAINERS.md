# Maintainers

Maintainers review and merge pull requests for their area and decide on changes to the contracts.

| Area | Maintainer |
|---|---|
| Repository, `source/` (services and libraries) | to be named |
| `apps/`, `packages/` | to be named |
| `contracts/` | to be named, one per partner |

Decisions that shape the repository are recorded under [docs/adr](docs/adr/README.md).
